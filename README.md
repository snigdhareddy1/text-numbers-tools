 Text and Number Tools

Description
A simple Python program that performs text and number operations.

Features
- Counts the words in a sentence.
- Finds the longest word.
- Reverses a sentence.
- Checks whether a number is prime.

Technologies Used
- Python 3
 How to Run
1. Open the terminal in VS Code.
2. Run the following command:

text_number_tools.py


3. Enter a sentence and a number when prompted.
